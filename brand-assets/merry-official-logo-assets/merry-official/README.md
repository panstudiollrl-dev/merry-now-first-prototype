# Merry Official Logo Assets

整理日期：2026-05-28

## Recommended Files

- `merry-mark-symbol-300.png`
  - 用途：mobile app header 中間的 compact M mark。
  - 建議 Stitch / Figma 優先使用這個。

- `merry-mark-symbol-512.png`
  - 用途：需要較高解析的 icon、splash、asset library。

- `merry-wordmark-565.png`
  - 用途：MERRY wordmark，不含公司英文名。
  - 可用於品牌展示、cover、小型 presentation。

- `merry-corporate-lockup-large-1265.png`
  - 用途：完整公司 lockup，大型品牌場景。

- `merry-corporate-lockup-compact-565.png`
  - 用途：較小版公司 lockup。

- `merry-mark-with-company-stacked-300.png`
  - 用途：方形品牌區塊、About / device info。

## Usage Rule

Mobile main app header:
- Use `merry-mark-symbol-300.png` or `merry-mark-symbol-512.png`.
- Do not add repeated `Merry Hearing` text beside it.

Brand moments:
- Use `merry-wordmark-565.png` or full corporate lockups.

Clinical dashboard sidebar:
- Use `merry-wordmark-565.png` or `merry-corporate-lockup-compact-565.png`.
